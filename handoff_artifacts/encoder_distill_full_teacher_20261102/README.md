## 原因与下一步边界

可以确认当前配方LP弱约3pp、PT后期改善缓慢；不能从这些标量量化“轮数不足”和“信息差下限”各占多少。新旧还同时有teacher上下文、峰值LR降低10倍/floor降低50倍、100与141轮预算差异，不把掉点归为MSE普遍无效。

结构性风险：T(full)[ids]融合另675位置的信息，而S仅看到75位置；MSE可学习可预测部分，但增加epoch不会补回不可预测上下文。8层raw特征MSE可能存在层间尺度/折中，当前没有分层MSE、范数、方差来确认哪层主导或是否坍塌。仍下降也不能证明目标可完全拟合。

若只选一个下一步训练，建议先保持teacher full、mask90%、8层MSE、100轮及其它设置，只将整个LR曲线×10，变为1e-3→1e-4，以检验当前LR量级是否过于保守；这是建议，尚未修改代码/配置或启动实验。不要同时改mask/loss/轮数，也不承诺高LR必然恢复LP。若优先省算力，可做checkpoint99的短LR重启续训，但必须作为新日程记录；直接把epochs改200会在epoch100把LR从1e-5推回约5.5e-5，不等于单纯多跑相同floor。
